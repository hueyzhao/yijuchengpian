# 0.2.0 配音与配乐验证

日期：2026-10-25。本机 macOS Intel，使用已安装的 Tingting 中文系统声音，无新模型、无生成 API。

- TypeScript 检查、Skill 格式检查通过。
- `bun scripts/checkAudio.ts`：11 项回归通过，覆盖互斥主音轨、非法音量、三种非静音配乐、导入音轨混音、旧版无声模式、短音乐循环、缺失声音和旁白过长拒绝。
- 通过 Computer Use 在本机新版 TRAE 本地 Agent 模式实际调用成功。此处使用技能＋本地命令，没有将其算作 MCP 验证。
- 60 秒、6 镜中文系统配音＋gentle 配乐实际生成；各段从 0/10/20/30/40/50 秒开始，原始旁白每段约 4.2—4.6 秒，无需加速。
- 混音报告显示人声出现时压低音乐，峰值约 0.696（满幅为 1），未发生数字削波。无声旧功能与配音字段的启用行为保持兼容。
- 系统声音属于基础离线配音，配乐属于简单本地合成；未声明达到真人表演或商业作曲质量。

Windows System.Speech 适配已提供但没有 Windows 真机验证；没有已安装中文声音时返回明确错误。Linux 暂不支持自动系统配音，可导入录音并使用配乐。旧视频素材原声仍被去除。

## 0.2.1 字幕与配音修复（2026-10-26）

- 根因：此前字幕取 caption、配音可取 narration，来源不同；字幕覆盖整个镜头而声音提前结束。
- 自动配音改为短句合成并记录真实音频时长；烧录字幕与 SRT 共用同一组 cues。移除两端静音，句间保留停顿，旁白文本即字幕文本。
- 系统语速默认 170；最大时长适配加速从 1.35 降为 1.10。这是节奏调整，不是情感语音引擎。
- 本机 TypeScript 校验、12 项音频回归检查通过；包括 caption 与 narration 不同、短句顺序、留白、过长旁白报错。
- 60 秒样片重新合成，音视频各 60 秒；检查 1.52 秒、3.2 秒字幕变化与 7 秒字幕隐藏。使用系统 Tingting，全本地，无付费 API。
- 逐句对齐不是逐字对齐；25 fps 烧录有一帧量化误差。整条导入录音仍按镜头显示字幕，已增加明确警告。Windows 未真机复测。
