# 选一个风格，说出你的主题

一句成片提供六套创作模板，帮助 AI 安排剧情节奏、画面提示词、旁白和配乐。你不用自己研究提示词，直接说下面这样的话即可。

| 风格 | 可直接复制的需求 |
|---|---|
| 治愈绘本 | 用治愈绘本风格做一条 20 秒短片，讲小猫在雨夜帮助刺猬的故事。 |
| 悬疑故事 | 用悬疑故事模板做一条 30 秒短片，解释为什么空房间每天午夜都会亮灯，结尾要有铺垫的反转。 |
| 轻松科普 | 用轻松科普模板，20 秒解释为什么冰能浮在水上，语言适合孩子，知识要准确。 |
| 产品介绍 | 用产品介绍模板，做一条 30 秒的手工卡片介绍。我会提供真实产品照片和信息，不要编造卖点。 |
| 国风故事 | 用国风故事模板做一条 20 秒的水墨插画故事，讲修伞匠和一碗热汤，旁白通俗一点。 |
| 搞笑短剧 | 用搞笑短剧模板做一条 20 秒短片，小猫把“看好这盘鱼”理解成吃进肚子里。 |

每套都包含：剧情结构、画面风格描述、逐镜提示词骨架、旁白写法、声音与配乐建议，以及一份完整的 20 秒脚本示例。

## 不知道选哪套？

```text
我想用一句成片做一条关于“朋友之间互相帮助”的 20 秒视频。
请推荐一个适合的模板，并帮我写出故事和镜头安排。
缺少画面时引导我准备自己的素材，优先免费方案，不调用付费 API。
```

## 也可以混搭

```text
剧情按悬疑故事来写，画面采用国风水墨。
先给出完整故事和统一角色设定，再写每镜画面提示词。
保持结尾反转合理，不为了风格牺牲剧情。
```

## 看过计划后继续制作

```text
按这个方案继续。检查现有素材是否齐全；有缺失就告诉我如何生成或提供。
素材齐全后添加中文旁白、同步字幕和低音量配乐，制作成片。
不要把画面提示词当作已经生成的图片。
```

需要联网声音时另外明确：“允许免费联网配音，发送这段旁白文字，先给我试听。”

**模板不是滤镜或生图模型。** 画面风格需要相应素材或外部生成工具实现。目前仍输出横屏视频与固定样式字幕；专业国风音乐、悬疑音效、竖屏和转场没有因新增模板而自动具备。工作台和外部工具的额度费用依其实际规则。
