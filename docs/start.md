# 一句成片：从安装到第一条免费短片

## 第一步：拿到安装包

WorkBuddy 技能入口只上传文件名带 `workbuddy-skill` 的 ZIP。不要上传 GitHub 的 Source code 包或旧版 starter 包，否则可能因目录过深解析失败。

下载一句成片技能安装包并解压，里面包含 SKILL.md 和浅层参考文件，制作工具由工作台从 GitHub 安装。不需要自己编写代码。从 [GitHub 下载页](https://github.com/hueyzhao/yijuchengpian/releases/latest) 获取“yijuchengpian-0.3.2-workbuddy-skill.zip”。

## 第二步：打开工作台

使用 WorkBuddy、TRAE / TraeWork、Codex 或 Claude 中支持本地文件与工具的模式。能上传自定义技能 ZIP 的工作台可通过技能入口导入；否则打开解压目录，让工作台阅读 SKILL.md。不能假定每个软件都支持把 ZIP 拖进聊天后自动安装。

## 第三步：复制安装提示词

```text
请阅读我提供的一句成片 SKILL.md，按附带指引安装制作工具。
由你完成本地安装、依赖准备和工具连接，我不手动输入命令。
保留已有配置。需要授权时告诉我该点击什么。
安装后制作自带的 20 秒原创示例，先走免费方案，展示实际成片。
不要调用付费 API，不下载大模型。
```

首次安装需要联网下载依赖。工具无法运行时，AI 应说明具体原因；不能把“技能导入成功”当作“视频制作成功”。

## 第四步：试听配音

```text
先用一小段旁白试听。允许免费联网配音，将旁白文字发送给语音服务。
试中文女声或男声，不调用付费 API。没有网络时先告诉我，不要偷偷换声音。
```

不想联网时改说“只用本机系统配音”。自然度不同，听过再决定。

## 第五步：创作自己的故事

可以先选 [六套风格模板](styles.md)：治愈绘本、悬疑故事、轻松科普、产品介绍、国风故事、搞笑短剧。也可以只说主题，让 AI 推荐。

说出主题、时长和风格，例如“20 秒温暖小故事，雨夜的小猫和书店”。AI 先写故事，安排镜头，再引导你生成素材。没有免费的画面生成工具时，先拿到提示词与素材准备步骤；不会把未生成的图片说成已有素材。

## 第六步：生成、查看、修改

素材齐全后，让 AI 添加配音、字幕和配乐，制作 MP4。先检查声音、字幕是否一致，再修改剧情或声音。旧作品保留，新版本另存。

成片位置由工作台返回。一句成片本地合成免费，工作台模型和外部画面工具可能使用自身额度。
