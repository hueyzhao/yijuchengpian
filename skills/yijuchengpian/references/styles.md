# 六套创作风格：选择与执行

先按用户明确选择读取对应模板；用户只给主题时，推荐一套并说明一句理由，然后继续创作。不要求用户填写风格问卷，也不把推荐当成硬性限制。已有完整剧本或素材时优先保留，不为了套模板重写用户已确认的内容。

| 模板 | 适合的目标 | 读取文件 |
|---|---|---|
| 治愈绘本 | 温暖、陪伴、成长、亲子故事 | [healing.md](styles/healing.md) |
| 悬疑故事 | 谜题、异常线索、合理反转 | [mystery.md](styles/mystery.md) |
| 轻松科普 | 解释一个知识点、日常问题 | [science.md](styles/science.md) |
| 产品介绍 | 真实使用场景、单品或服务展示 | [product.md](styles/product.md) |
| 国风故事 | 东方意境、架空古风、传统题材 | [chinese.md](styles/chinese.md) |
| 搞笑短剧 | 日常误会、行为反差、轻喜剧 | [comedy.md](styles/comedy.md) |

按需只读一套；混搭时最多先读两套，说明“剧情用哪套、画面用哪套”。这些是开放的创作参考，不限制用户指定的其他风格。

## 从模板到制作

1. 确定主题、时长与素材情况。沿用已知信息；缺少时长时可先按 20 秒提出草案。
2. 输出简短创作计划：所选模板、一句话故事或中心信息、固定角色设定、分镜表。每镜列出时长、可见画面、完整生成提示词、实际旁白、素材状态。素材状态区分“已有”“待生成”“待用户提供”。按用户已有授权继续，不额外反复确认同一事项。
3. 写画面提示词时填入角色、动作、场景、构图、风格。角色完整描述写进每镜 visual；单独的提示词文件可加更丰富的美术描述。画面工具没有就提供准备方法，不伪造素材文件。
4. 素材齐全后按 schema.md 编写 story.json。模板名称和美术说明放在独立的 creative-plan.md，不向严格故事格式添加 style、emotion、camera、transition 等未支持的字段。
5. 配音以 narration（未提供则 caption）为准，字幕共用相同文字。caption 每镜最多 48 字且需满足现有字数校验；较长旁白可使用 narration，但必须试听确认时长。生成前验证时长、素材和角色信息。
6. 模板的 voice/rate/music 建议均为可选，用户意见优先。选择联网声音仍需要发送旁白文字的授权；选择模板不是联网授权，也不是使用付费画面工具的授权。

## 当前能做与不能做

- 六套模板控制创作文案与画面提示词，不会改变已有图片的美术风格，也不会自动连接不存在的画面工具。
- 画面仍是固定横屏 1280×720；图片静态展示，视频按时长编排。字幕仍为底部白字、半透明黑底，没有主题花字、竖屏、转场或推拉运镜设置。
- 内置音乐只有 gentle / bright / calm，都是简单合成音色；“国风”“悬疑”等题材不代表已有对应专业音乐。可以不配乐，或导入用户有权使用的音轨。
- 当前一部视频选择一种配音声音；不能许诺自动多角色配音或任意情绪表演。
- 20 秒示例仅演示分镜与文案，不是已经生成并审核过的六部样片。
