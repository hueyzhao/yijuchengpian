# 一句成片首次安装指引

本文件供宿主 AI 执行。用户通过对话安装，不需要自行输入终端命令或修改配置。

## 检查与放置

- 检查宿主是否能读写本地文件和执行本地工具。只有网页聊天或仅能读附件时，说明需要切换到本地任务模式；不要宣称安装成功。
- 优先复用已安装的一句成片和可用的 yijuchengpian MCP。不要覆盖其他连接器、已有作品或用户设置。
- 此技能目录下若存在 `assets/app/package.json`，它是随包附带的制作工具。将完整 `assets/app/` 复制到用户选择的长期保存目录下的 `yijuchengpian` 子目录，保留权限。目标已存在时先检查，不能直接覆盖。记住这个路径；不要在临时附件目录中长期保存作品。
- 仓库版可能没有 `assets/app/`。此时使用包含此技能的一句成片仓库根目录；若没有源码，从 https://github.com/hueyzhao/yijuchengpian 获取源码到用户授权的目录，或使用发布页的完整安装包。只读取明确相关文件，不扫描用户全部文件。

## 安装制作工具

- macOS：在源码根目录执行 `bash install.command`。脚本会复用 Bun，或从 bun.sh 安装 Bun，然后安装锁定的依赖并生成本地配置。
- Windows：在源码根目录执行 `install.ps1`。如系统策略阻止执行，说明拦截原因与需要用户完成的操作，不自动绕过系统安全策略。
- Linux 暂不承诺一键安装。当前运行时需 Bun、FFmpeg 和可用中文字体；缺失时如实说明。
- 首次安装需联网下载运行环境、FFmpeg 等依赖，不下载 AI 大模型，不调用收费生成 API。若下载失败，保留日志，说明是下载还是运行失败，不假装继续完成。
- 脚本生成 `local/mcp.json`，其中是此机器的绝对路径，不要将其上传或用于其他电脑。将其中 yijuchengpian 配置按宿主实际支持的方式合并，保留其他服务器。如果宿主配置格式不同，依据其当前文档适配，不猜测配置目录。
- 若需要用户在界面导入配置或重启连接器，给出具体步骤。无法自动注册时，可使用宿主的本地命令能力继续试用，不必阻塞在 MCP 上。

## 真实验收

1. 在源码根目录运行 `bun start doctor`，或调用 `yijuchengpian_status`，确认 FFmpeg、中文字体和工作目录可用。若 Bun 不在 PATH，使用安装时实际找到的绝对路径，并在后续运行时加入其目录。
2. 用户要求试用时运行 `bun run demo`，它会在工作目录生成原创四幅插画和一条 20 秒无声字幕 MP4，不需用户素材。此命令是实际生成示例，并非仅写剧本。
3. 从真实输出取得视频路径，确认状态 completed 和文件非空，打开预览或提供可点击本地文件。向用户说明这是静态插画故事片，不是连续人物动画。
4. 如已配置 MCP，用 `yijuchengpian_status`、`yijuchengpian_validate` 验证工具连接。仅本地命令生成成功时，明确只验证了本地制作，没有把 MCP 配置成功算作工具调用成功。
5. 只有技能被加载、状态检查通过且样片实际生成，才报告首次试用完成。重复安装时优先复用；渲染超时先查 output 中任务状态，避免重复提交。

## 后续使用

读取 `schema.md`，使用状态检查返回的工作目录。素材先复制到其子目录，再用相对路径编写 story.json；校验和渲染都从相同源码根目录执行。可按用户要求启用 voiceover 和 music，查看 schema.md；没有中文系统声音时先说明。默认不调用收费服务。没有画面时，先帮用户创作角色设定与提示词，再按可用工具与用户选择准备素材，不把提示词当图片。
